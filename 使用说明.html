User Manual · 使用说明

鹅掌楸多组学数据库
Liriodendron Multi-omics Database

LMDB v3.0  ·  南京林业大学  ·  2026

🚀 快速开始（首次使用）

1

安装 Python（仅首次需要）

前往 python.org/downloads 下载并安装 Python 3.8 或更高版本。安装时必须勾选 "Add Python to PATH"。

2

将软件文件夹复制到电脑任意位置

整个 2026_3_4 文件夹可放在任意盘符、任意路径，软件使用相对路径，无需修改任何配置。

3

双击 启动.bat 启动数据库

脚本将自动检测 Python、启动基因组查询服务器，并在默认浏览器中打开数据库主页。

4

在浏览器中正常使用

推荐使用 Chrome 或 Edge 浏览器。核心功能无需联网。

⚠️
注意： 启动.bat 运行后会弹出一个命令行窗口（基因组服务器），请勿关闭该窗口，否则基因序列查询功能将停止工作。
📦 功能模块介绍
🧬

基因组序列查询

根据基因 ID 查询中国/北美鹅掌楸的基因组序列、CDS、蛋白质序列及启动子区域，支持批量下载。

需要启动服务器
📊

基因表达量分析

集成多个转录组数据集（体胚发生、冷胁迫等）的 FPKM 表达量矩阵，支持基因表达可视化与比较。

内嵌数据，无需网络
🗺️

样本地理分布

展示鹅掌楸 NCBI SRA 样本的地理来源信息，支持交互式地图浏览与样本信息检索。

地图需联网加载
🔗

比较基因组学

提供中国鹅掌楸与北美鹅掌楸的共线性分析结果，支持染色体级别的基因组比较可视化。

独立 HTML 模块
🧬

四倍体剂量效应分析

分析四倍体鹅掌楸中基因剂量效应类别，包含火山图、MA 图、热图等多种可视化方式。

独立 HTML 模块
🔬

引物设计工具

支持 qPCR 引物设计、克隆引物设计，根据基因 ID 自动提取 CDS 序列并推荐引物方案。

内嵌工具
🌵️

冷胁迫转录组

包含多个物种冷胁迫条件下的基因表达量数据，支持跨物种基因表达比较分析。

内嵌数据
🌿

体胚发生转录组

鹅掌楸体胚发生各阶段的基因表达动态，支持差异表达基因的筛选与模块分析。

内嵌数据

❓ 常见问题
Q双击启动.bat 提示"未找到 Python"怎么办？
请前往 python.org/downloads 安装 Python，安装时务必勾选 "Add Python to PATH"，安装完成后重新双击 启动.bat。
Q基因序列查询没有结果？
请确认 启动.bat 弹出的黑色命令行窗口仍在运行（不要关闭它）。如已关闭，请重新双击 启动.bat。
Q地图无法显示？
地图功能需要网络连接加载 Leaflet 地图库。其他所有功能均可完全离线使用。
Q能在多台电脑上同时使用吗？
可以。将整个 2026_3_4 文件夹分别复制到每台电脑，各自安装 Python 后即可独立使用。
Q端口 7788 被占用怎么办？
说明基因组服务器已在运行中（上次未关闭），直接双击 启动.bat 打开主页即可正常使用。
Q页面字体显示异常？
字体从 Google Fonts 在线加载，建议首次在有网络环境下打开一次，浏览器会缓存字体，之后离线也能正常显示。
Q可以放在 U 盘上使用吗？
可以，但 U 盘读写较慢可能影响基因组查询性能。建议复制到本地硬盘后使用，体验更流畅。
